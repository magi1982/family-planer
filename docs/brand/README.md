# Brand

Design language for this and future integrations:

- **Tile:** squircle, charcoal gradient `#2A2E33 → #17191C`.
- **Signature:** green corner tab top right (`#69C350`, circle r=150 at the corner) with a faint ring (r=176, 35 % opacity).
  Every integration keeps the tab; only the pictogram changes. A sub-brand may change the tab colour.
- **Pictogram:** white `#F4F6F8` line icon, stroke 30 px on 512, round caps and joins, centred, no text.
- **Wordmark:** first word ExtraBold, second word Light, green underline bar (120 × 14, radius 7).

Masters: `family-planer.svg`, `logo-wordmark.svg`. Examples: `demo-energy.svg`, `demo-garden.svg`.
